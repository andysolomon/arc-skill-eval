These examples include the skill, eval suite, commands, and generated artifacts.

## Available now

- [hello-world](/arc-skill-eval/examples/hello-world/) is the reference skill included with `arc-skill-eval`. Its three cases use `file-exists`, `regex-match` against files and responses, and a judged assertion. A run usually takes about 30 seconds.

Planned examples will cover fixtures, conflict tests, and `--compare` runs. To suggest a skill with `evals/evals.json`, [open an issue](https://github.com/andysolomon/arc-skill-eval/issues).
